# Tresor Mugisha - Portfolio

Personal portfolio website showcasing software engineering projects and professional experience.

## Live Site

https://tresormu.github.io/

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: GitHub Pages (Static Export)

## Features

- Responsive design with mobile-first approach
- Project showcase with detailed descriptions
- Interactive project detail pages
- Resume/CV download functionality
- Clean, modern UI inspired by minimalist design principles

## Projects

Featured projects include:
- **IkiminaPass** - ROSCA Platform for Rwanda (Fintech)
- **MamaCare** - Maternal Health Platform (Healthcare)
- **TheYouthContest** - Debate Championship Platform (EdTech)
- **Job Portal** - Full-Stack Recruitment Platform (HR Tech)
- **BDifferent** - E-Commerce Platform (Retail)
- **ShieldKids** - Child Safety App (Private project)

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deployment

This site uses Next.js static export for GitHub Pages deployment. The `out/` directory contains the production build which is deployed to the repository root.
